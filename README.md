Fractal Renderer GPU

Renders fractals (Mandelbrot, Julia) on the GPU

Uses basic python libraries (pygame numpy moderngl sys)

Can be ran as is.

Controls:
- WASD : Pan view
- Mouse wheel / Left click : Zoom in
- Right click : Start/stop zoom out animation
- Arrow keys : Adjust constants used to calculate the fratal (Only affects Julia set)
- Q / E : Decrease / Increase max iterations (adjusts how detailed fractal is)
- R : Reset view
- Space : Switch fractal mode
- ESC : Quit

Features:
- High-precision calculations with doubles
